# JevHub V0.1 Product Spec

状态：**Frozen for V0.1 planning**  
目标域名：**https://jevhub.xyz**  
外部商店：**https://jevhub.store**  
默认语言：**English-first**。现已批准提供中文（简体）切换，中文本地化路由使用 `/zh-CN/...`；为保持 V0.1 的 16 个可索引页面，中文路由统一 `noindex` 且不进入 sitemap。

## 1. 产品定位

JevHub V0.1 不是充值站，也不是另一个 Jev Playground。

它是一个独立的第三方入口站：

> Learn Jev, estimate its cost, copy practical decision templates, and discover the Jev ecosystem.

V0.1 要回答四类用户问题：

1. Jev 是什么？
2. Jev 怎么用、多少钱？
3. 有哪些可以直接参考的 Jev 决策模板？
4. Jev 周边已经有哪些 SDK、工具和项目？

## 2. 与 jevhub.store 的边界

### JevHub（本仓库）

负责：

- SEO / 教程
- 定价说明
- 成本计算器
- 静态 Templates
- 精选 Ecosystem
- 外部 Store 跳转与点击统计

不负责：

- 支付
- 充值
- Credits 转移
- 订单
- 兑换码
- 用户余额
- 账本
- Store 登录/后台

### jevhub.store（另一个项目）

负责所有购买相关流程。

本仓库只有：

`GET /go/store` → 临时跳转到 `https://jevhub.store/?utm_source=jevhub.xyz&utm_medium=referral&utm_campaign=store`

要求：

- 使用非永久跳转（目标未来可变）
- `/go/store` noindex
- 不进入 sitemap
- 记录一个 `store_click` analytics event
- 页面和代码中不要复制 Store 的业务逻辑

## 5. Jev Cost Calculator

### 输入

- Average input tokens per request（整数，>= 0）
- Requests per day（整数，>= 0）
- 可切换成 Requests per month（二选一，不同时输入）
- 当前官方计价单位从统一 pricing config 读取

### 输出

- Cost per request
- Tokens per day / month
- Cost per day
- Cost per month
- Cost per year

### 公式

设：

- `T` = average input tokens/request
- `R` = requests/day
- `P` = price per 1,000,000 input tokens

则：

- Daily tokens = `T * R`
- Daily cost = `T * R / 1_000_000 * P`
- Monthly cost = daily cost × 30.4375
- Annual cost = daily cost × 365.25

如果用户按月输入请求量，则月成本直接按月请求量计算，年成本按 12 倍展示。

### 价格数据规则

建立单一文件，例如：

`src/data/jev-pricing.ts`

至少包含：

- model/product identifier
- currency
- pricePerMillionInputTokens
- pricePerMillionOutputTokens（若官方为 0，也显式写出）
- sourceUrl
- lastVerifiedAt
- notes

任何页面都不得硬编码第二份 Jev 价格。

## 6. Templates

V0.1 的 Template 是“静态学习模板”，不是在线运行器。

每个 Template 页面固定结构：

1. H1 + 一句话用途
2. When to use it
3. Example state
4. Decision questions
5. Choice / Score / Noul explanation
6. Expected structured output
7. TypeScript sample
8. Why this design works
9. Limits / when not to use it
10. Copy code

模板数据统一 typed schema，建议：

```ts
type JevTemplate = {
  slug: string
  title: string
  description: string
  category: "support" | "sales" | "safety" | "agents"
  useCases: string[]
  stateExample: Record<string, unknown>
  questions: Array<{
    id: string
    type: "choice" | "score" | "noul"
    instruction: string
    criteria?: Record<string, string | null>
  }>
  typescriptExample: string
  sourceNotes: Array<{
    label: string
    url: string
    kind: "official" | "community" | "original"
  }>
}
```

V0.1 不需要 Python 示例，避免重复维护。Python 留 V0.2。

## 7. Ecosystem

V0.1 只做一个页面，20–30 个精选条目。

分类上限：

- Official
- SDKs
- Integrations
- Playgrounds
- Agent / Tooling
- Open Source / Research

每个条目：

- name
- one-sentence description（JevHub 自己写）
- category
- GitHub URL（如有）
- website URL（如有）
- source
- lastCheckedAt

不做：

- 单独详情页
- star 实时同步
- 用户提交
- 排名
- 评分
- 评论
- Featured paid listing

## 8. 设计与品牌

- 品牌：JevHub
- 域名：jevhub.xyz
- 视觉：开发者工具/知识站，不做商城视觉
- 不使用 TypeSafe 官方 logo/配色到可能造成官方混淆
- 全站 Footer 必须有：
  - `Independent community resource. Not affiliated with or endorsed by TypeSafe AI.`
- 外部链接明确显示外链图标
- JevHub Store 是外部站点，不让用户误解为当前页面的内置结账流程

## 9. 非目标

V0.1 明确不解决：

- Jev API 在线试用
- 账号/API Key 管理
- Jev credits 转售机制
- 社区账户体系
- Newsletter
- 用户生成内容
- 付费会员
- SEO 批量页面
- 自动同步 GitHub 项目

这些只有在 V0.1 上线取得数据后才允许讨论。

## 10. V0.1 成功指标

上线后至少观察 2–4 周：

- Search Console impressions by page/query
- Organic clicks
- Calculator usage
- Template copy clicks
- Ecosystem outbound clicks
- Store click-through rate
- Returning visitors

V0.1 不以“功能数量”作为成功指标。
