# JevHub V0.1 Product Spec

状态：**Frozen for V0.1 planning**  
目标域名：**https://jevhub.xyz**  
外部商店：**https://jevhub.store**  
默认语言：**English-first**。现已批准提供中文（简体）切换，中文本地化路由使用 `/zh-CN/...`；英文 V0.1 现为 18 个英文可索引页面，中文镜像统一 `noindex` 且不进入 sitemap。

2026-09-21 scope amendment：批准新增公开 `/playground`。Playground 使用 JevHub 服务端 `TYPESAFE_API_KEY` 调用 TypeSafe；浏览器不得接触密钥，也不得提供用户 API Key 输入框。

2026-09-23 scope amendment：批准新增 `/apps/startup-idea-validator`，作为 JevHub 第一个 Real App。它与 Playground 共用服务端密钥边界，但只接受 idea + goal，并固定执行 8 个 Score questions。

## 1. 产品定位

JevHub V0.1 不是充值站。它既是 Jev 学习入口，也允许少量经过边界约束的真实 Jev 应用体验。

它是一个独立的第三方入口站：

> Learn Jev. Try real apps. Build with it.

V0.1 要回答五类用户问题：

1. Jev 是什么？
2. 不写代码时，Jev 做出来的真实产品体验是什么样？
3. Jev 怎么用、多少钱？
4. 有哪些可以直接参考的 Jev 决策模板？
5. Jev 周边已经有哪些 SDK、工具和项目？

## 2. 与 jevhub.store 的边界

### JevHub（本仓库）

负责：

- SEO / 教程
- 受限 Real Apps（当前仅 Startup Idea Validator）
- Jev Playground
- 定价说明
- 成本计算器
- 静态 Templates
- 精选 Ecosystem
- 外部 Store 跳转与点击统计

不负责：

- 支付
- 充值
- Credits 转移
- 订单
- 兑换码
- 用户余额
- 账本
- Store 登录/后台

### jevhub.store（另一个项目）

负责所有购买相关流程。

本仓库只有：

`GET /go/store` → 临时跳转到 `https://jevhub.store/?utm_source=jevhub.xyz&utm_medium=referral&utm_campaign=store`

要求：

- 使用非永久跳转（目标未来可变）
- `/go/store` noindex
- 不进入 sitemap
- 记录一个 `store_click` analytics event
- 页面和代码中不要复制 Store 的业务逻辑

## 5. Jev Cost Calculator

### 输入

- Average input tokens per request（整数，>= 0）
- Requests per day（整数，>= 0）
- 可切换成 Requests per month（二选一，不同时输入）
- 当前官方计价单位从统一 pricing config 读取

### 输出

- Cost per request
- Tokens per day / month
- Cost per day
- Cost per month
- Cost per year

### 公式

设：

- `T` = average input tokens/request
- `R` = requests/day
- `P` = price per 1,000,000 input tokens

则：

- Daily tokens = `T * R`
- Daily cost = `T * R / 1_000_000 * P`
- Monthly cost = daily cost × 30.4375
- Annual cost = daily cost × 365.25

如果用户按月输入请求量，则月成本直接按月请求量计算，年成本按 12 倍展示。

### 价格数据规则

建立单一文件，例如：

`src/data/jev-pricing.ts`

至少包含：

- model/product identifier
- currency
- pricePerMillionInputTokens
- pricePerMillionOutputTokens（若官方为 0，也显式写出）
- sourceUrl
- lastVerifiedAt
- notes

任何页面都不得硬编码第二份 Jev 价格。

## 6. Templates

V0.1 的 Template 是“静态学习模板”，不是在线运行器。

每个 Template 页面固定结构：

1. H1 + 一句话用途
2. When to use it
3. Example state
4. Decision questions
5. Choice / Score / Noul explanation
6. Expected structured output
7. TypeScript sample
8. Why this design works
9. Limits / when not to use it
10. Copy code

模板数据统一 typed schema，建议：

```ts
type JevTemplate = {
  slug: string
  title: string
  description: string
  category: "support" | "sales" | "safety" | "agents"
  useCases: string[]
  stateExample: Record<string, unknown>
  questions: Array<{
    id: string
    type: "choice" | "score" | "noul"
    instruction: string
    criteria?: Record<string, string | null>
  }>
  typescriptExample: string
  sourceNotes: Array<{
    label: string
    url: string
    kind: "official" | "community" | "original"
  }>
}
```

V0.1 不需要 Python 示例，避免重复维护。Python 留 V0.2。

## 11. Playground scope amendment

`/playground` 与 `/apps/startup-idea-validator` 是 V0.1 唯一批准的在线 Jev runtime 入口。Playground 允许受约束的通用结构化问题；Idea Validator 只接受 idea + goal，并由服务端固定 8 个 Score 问题。

Playground：

- 仅接受 text state + 1–4 个 Choice/Noul/Score 问题
- state、问题长度、criteria 数量均有硬上限
- 浏览器不接触 `TYPESAFE_API_KEY`
- 不允许用户提交或保存自己的 API Key
- 服务端只转发到 TypeSafe `/v1/systemone`，不是通用代理
- 默认每 IP 每小时有基础限流；上线时仍应叠加 CDN/WAF 层限流
- 不记录用户 state 到数据库


## 12. Startup Idea Validator amendment

Route: `/apps/startup-idea-validator`

V0 只验证一个问题：用户是否愿意直接使用 Jev 做成的成品体验。

固定边界：

- 无登录、无数据库、无历史记录。
- 输入：idea 文本 + `money | open_source | fun`。
- 服务端固定生成 8 个 Score 问题，一次调用 TypeSafe System One。
- Jev 只负责返回结构化评分；总分、权重、KILL/FIX/SHIP 阈值由 JevHub 普通代码计算。
- 页面必须明确：这是对“用户描述的 idea”的结构化评估，不是独立市场调查，不验证竞争、法规、客户访谈或真实付费意愿。
- API Key 只在服务端。
- Idea 原文不得写入 GA4 / Umami analytics。
- 记录漏斗事件：view / submit / result / retry / share。
- V0 不做 Reality Check、Google/Reddit research、用户账户、结果历史或 Apps marketplace。

SEO：

- 页面主意图：startup idea validator / AI idea validator / should I build this。
- 首页继续主攻 Jev / Jev AI，不与 App 页面争同一主关键词。
- App 页面 self-canonical，并进入英文 sitemap。
- 非英文 V0.1 页面仍 noindex；本 App 暂不发布 locale 镜像。
